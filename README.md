## Importante

Para **ver** los archivos no se necesita permiso de edición. Para que el profesor pueda **guardar cambios directamente en tu repositorio**, su cuenta de GitHub necesita permiso de escritura. Sin ese permiso puede abrir los diagramas y revisarlos, pero no guardar directamente sobre tu rama `main`.
