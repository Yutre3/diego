## Herramientas y criterio de trabajo

- **Diagramas UML y modelo de datos:** se construyeron siguiendo la notación y las reglas explicadas en los materiales del profesor. Los archivos `.drawio` se dejan únicamente como **fuente editable**; Draw.io es el editor elegido para poder modificarlos desde GitHub, no una herramienta exigida por el material.
- **Diseño de interfaz:** se sigue la secuencia **Sketch → Wireframe → Mockup → Prototipo**, igual que en el material de clase.
- **Prototipo funcional web:** implementado con **HTML, CSS y JavaScript**.
- **Repositorio y control de versiones:** el proyecto está alojado en **GitHub** y queda preparado para trabajar con **Git y VS Code**, que son las herramientas mostradas en el material de Git/GitHub/VS Code.
