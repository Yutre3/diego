## URL de la página funcional

**https://yutre3.github.io/diego/**

La URL abre el prototipo navegable del hotel. La interfaz funcional mantiene la misma línea visual del mockup: barra superior, menú lateral, módulos de Habitaciones, Huéspedes, Reservas, Check-in, Check-out, Usuarios e Informes.
