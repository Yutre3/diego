# Diagramas editables

Esta carpeta contiene las **fuentes visuales editables** de los diagramas.

Los archivos `.drawio` no son imágenes planas: cada caja, texto, línea y flecha se puede seleccionar y modificar en **diagrams.net / draw.io**.

## Cómo funciona

1. Presiona **Abrir y editar visualmente**.
2. diagrams.net abre el archivo guardado en GitHub.
3. La primera vez puede pedir autorización de GitHub.
4. Cada elemento del diagrama es editable: texto, cajas, conectores, flechas y posiciones.
5. Al guardar, diagrams.net puede guardar los cambios de vuelta en el repositorio si la cuenta tiene permisos de escritura.

Los archivos están guardados en la rama `main`.
