# Prototipo navegable

Este prototipo aplica la última etapa del material de interfaz: después del sketch, wireframe y mockup, se construye una versión navegable.

## Cómo abrirlo

1. Descargar o clonar el repositorio.
2. Entrar a la carpeta `prototipo`.
3. Abrir `index.html` en el navegador.

## Qué permite probar

- navegación entre Inicio, Habitaciones, Huéspedes, Reservas, Check-in, Check-out e Informes;
- registro de una reserva de demostración;
- cambio de estado visual de una habitación;
- validación simple de campos requeridos;
- simulación de check-in y check-out.

No corresponde a la aplicación final ni utiliza una base de datos real. Su objetivo es probar navegación, distribución e interacción.
