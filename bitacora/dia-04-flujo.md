# Día 4 - Diagrama de flujo

## Objetivo
Mostrar el orden lógico de las operaciones principales.

## Qué se hizo
Se diseñó un flujo general desde el inicio de sesión hasta la selección de operaciones del sistema.

Se incluyeron tres procesos centrales:
- reservas;
- check-in;
- check-out.

Cada proceso termina actualizando la base de datos y permitiendo volver al menú o finalizar.

## Archivos relacionados
- docs/04_diagrama_flujo.md
- diagramas/fuentes_dot/diagrama_flujo.dot

## Resultado
Se obtuvo una representación secuencial de cómo se mueve la información dentro del sistema.

## Pendiente
Diseñar las entidades y relaciones de base de datos.

## Cómo explicarlo
"El caso de uso dice qué puede hacer el usuario; el diagrama de flujo muestra en qué orden ocurre el proceso."
