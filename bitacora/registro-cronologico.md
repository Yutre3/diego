## Formato que se usará desde el próximo avance

Cada jornada nueva debe registrar:

- fecha;
- hora de inicio;
- hora de término;
- objetivo;
- actividades realizadas;
- decisiones;
- archivos modificados;
- resultado;
- pendientes;
- commit asociado;
- explicación breve para la exposición.
