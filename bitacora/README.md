# Bitácora diaria del proyecto

Esta carpeta documenta el avance del proyecto por jornadas de trabajo.

La idea es que el repositorio permita demostrar **qué se hizo cada día, por qué se hizo, qué archivos se modificaron y qué quedó pendiente**. No se documenta solo el resultado final.

> Importante: como no se proporcionaron fechas reales de cada jornada, los registros están organizados como Día 1, Día 2, etc. Antes de entregar, pueden reemplazarse por las fechas reales si el profesor las solicita.

## Jornadas

1. Día 1 - Comprensión del caso y alcance.
2. Día 2 - Requerimientos y reglas de negocio.
3. Día 3 - Casos de uso.
4. Día 4 - Diagrama de flujo.
5. Día 5 - Modelo de datos y normalización.
6. Día 6 - Mockups de interfaz.
7. Día 7 - Kanban y trazabilidad.
8. Día 8 - Revisión, informe y preparación de exposición.

Cada jornada contiene:
- objetivo;
- actividades realizadas;
- decisiones tomadas;
- archivos relacionados;
- resultado;
- pendientes;
- qué se puede explicar al profesor.
