# 00 - Mapa de materiales aplicados al proyecto

Este archivo muestra cómo se utilizó cada material entregado en clases dentro del proyecto del Hotel Duerme Bien.

| Material entregado | Aplicación en el repositorio |
| --- | --- |
| Definición de proyectos(1).docx | Caso 6, requerimientos y entregables: docs/01_requerimientos.md y docs/evaluacion-2-modelado.md |
| CASOS_DE_USO_como_iniciar(1).pdf | Actores, casos de uso, relaciones y construcción del diagrama: docs/03_casos_de_uso.md y docs/13_casos_uso_material_aplicado.md |
| CASOS_DE_USO_extend_y_include(1).pdf | Uso de include y extend: docs/03_casos_de_uso.md |
| UML_CASOS_DE_USO(1).jpg | Ejemplo simple Recepcionista / Check-in / Check-out: diagramas/casos-de-uso-checkin-checkout.svg |
| UML_CASOS_DE_USO_2(1).jpg | Estructura de ejemplo con operación general, include y extend: diagramas/casos-de-uso-estructura-atm-adaptada.svg |
| diagrama_de_procesos(1).jpg | Inicio, captura de datos, decisión, retorno y registro en BD: diagramas/flujo-validacion-ejemplo.svg |
| Diagramas de Clase(1).pdf | Nombre, atributos, operaciones, relaciones y multiplicidad: docs/10_diagrama_clases.md |
| GUIA_diagramas_de_clase(1).pdf | Construcción paso a paso, relaciones y cardinalidad: docs/10_diagrama_clases.md y diagramas/diagrama-clases-completo.svg |
| MODELO_E_R_NORMALIZACION.pdf | 1NF, 2NF, 3NF y separación de entidades: docs/09_normalizacion.md |
| MOCKUP_COMPLETO(1).pdf | Sketch, wireframe, mockup y prototipo: docs/06_mockups.md, sketch/, wireframes/, mockups/ y prototipo/ |
| Github_Git_VSCode.docx | Git, GitHub, VS Code, clonado, commits y ramas: docs/12_git_github_vscode.md |

## Criterio

Los ejemplos se adaptan al Sistema de Pasajeros del Hotel Duerme Bien. Cuando un material contiene contenido complementario que no aparece como entregable obligatorio, se identifica como complemento y no como requisito oficial del Caso 6.

Los archivos originales del profesor no se duplican; se aplican sus estructuras y ejemplos al tema del proyecto.
