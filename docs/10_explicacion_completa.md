# Explicación completa del proyecto

## 1. Qué problema resolvemos
El hotel Duerme Bien trabaja con planillas Excel y necesita un sistema para gestionar habitaciones y pasajeros. El sistema propuesto centraliza reservas, disponibilidad, check-in, check-out, costos, usuarios e informes.

## 2. Cómo trabajamos
El desarrollo se organizó en jornadas. Cada jornada quedó documentada dentro de `bitacora/`.

El orden fue:
1. entender el caso;
2. definir requerimientos;
3. modelar casos de uso;
4. construir el flujo;
5. diseñar la base de datos;
6. diseñar las pantallas;
7. organizar y trazar el trabajo;
8. revisar y preparar la exposición.

## 3. Por qué usamos GitHub
GitHub permite mantener los archivos ordenados, conservar historial de cambios, dejar evidencia de cada avance y centralizar la documentación.

## 4. Relación entre las partes
Los requerimientos indican qué debe hacer el sistema. Los casos de uso muestran quién hace cada acción. El flujo muestra el orden de los procesos. El modelo de datos define dónde se guarda la información. Los mockups muestran cómo interactuará el usuario. Kanban organiza el trabajo y la trazabilidad conecta todas esas piezas.

## 5. Qué es oficial y qué es propuesta
Las funciones principales vienen del Caso 6. Los detalles que el caso no define, como atributos específicos o una fórmula exacta de costos, se marcaron como propuestas o supuestos para no presentarlos como requisitos entregados por el profesor.
