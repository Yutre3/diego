# Páginas e imágenes editables

Todo el proyecto queda guardado como archivos fuente dentro del repositorio. El profesor puede **ver el resultado**, **abrir el código** y, si tiene permisos de escritura en el repositorio, usar el botón del lápiz de GitHub para editar directamente.

> Si una persona no tiene permisos de edición, GitHub normalmente permite crear un fork y proponer cambios mediante Pull Request.

## Cómo editar desde GitHub

1. Abrir el archivo.
2. Presionar el ícono del lápiz **Edit this file**.
3. Modificar texto, HTML, CSS, JavaScript o SVG.
4. Escribir un mensaje de commit.
5. Guardar con **Commit changes**.

Los archivos SVG también son editables porque están guardados como código de texto, no como una imagen cerrada.

## Importante sobre permisos

Para editar directamente el repositorio, el profesor necesita permisos de escritura. Si solo tiene acceso público, puede verlo y descargarlo; para editar directamente debe agregarse como colaborador o trabajar mediante fork/Pull Request.
