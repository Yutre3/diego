# Preguntas que podría hacer el profesor

## ¿Cuál es el problema que resuelve el proyecto?
El hotel trabaja con planillas Excel y necesita centralizar la gestión de habitaciones, huéspedes, reservas, check-in y check-out.

## ¿Cuáles son los actores principales?
Administrador y Encargado de hotel.

## ¿Qué diferencia hay entre actor y caso de uso?
El actor representa el rol que interactúa con el sistema. El caso de uso representa una acción que ese actor puede realizar.

## ¿Qué significa include?
Significa que un caso de uso necesita ejecutar otro caso de uso como parte de su funcionamiento.

## Dame un ejemplo de include
Realizar check-out incluye calcular costo y liberar habitación.

## ¿Para qué sirve el diagrama de flujo?
Para representar el orden lógico de las actividades y decisiones dentro de un proceso.

## ¿Cuáles son las entidades principales?
Usuario, Habitación, Huésped, Reserva y Estadía, además de tablas puente para relacionar huéspedes con reservas y estadías.

## ¿Por qué normalizar la base de datos?
Para reducir datos repetidos, mantener consistencia y organizar correctamente las relaciones.

## ¿Qué es un mockup?
Una representación visual de cómo se verá una pantalla antes de desarrollar la aplicación.

## ¿Para qué sirve Kanban?
Para organizar las tareas según su estado: pendiente, en progreso o terminado.

## ¿Qué es trazabilidad?
Es la relación entre un requerimiento y los elementos que lo implementan o representan, como casos de uso, datos y pantallas.

## ¿Por qué usaron GitHub?
Para almacenar el proyecto, registrar cambios mediante commits y mantener evidencia del proceso de trabajo.

## ¿Qué diferencia hay entre Git y GitHub?
Git es el sistema de control de versiones. GitHub es una plataforma que aloja repositorios Git y facilita compartir y revisar el trabajo.

## ¿Qué cosas fueron propuestas y no venían directamente en el caso?
Algunos detalles del modelo de datos, validaciones y la fórmula exacta del costo. Por eso quedaron identificados como propuestas o supuestos.

## ¿El sistema ya está programado?
No. Este trabajo corresponde al análisis, requerimientos y modelado del sistema. Los mockups y el modelo de datos preparan una implementación posterior.

## ¿Cómo pueden demostrar el trabajo realizado?
Mediante los archivos del repositorio, la bitácora y el historial de commits.
